# Ponys.ai Publisher Resources

This documentation helps publishers, reviewers, developers, and researchers
reuse Ponys.ai product metadata without scraping pages or inventing capability
claims. The material is maintained by the Ponys.ai team and should be treated
as a first-party source.

## Product paths

Use the destination that best matches the reader's task:

| Reader intent | Destination |
| --- | --- |
| Browse public characters | [Discover AI characters](https://ponys.ai/discover) |
| Start a character workflow | [Create an AI character](https://ponys.ai/create) |
| Generate a character concept | [AI character generator](https://ponys.ai/ai-character-generator) |
| Create character imagery | [AI image generator](https://ponys.ai/ai-image-generator) |
| Explore character video | [AI video generator](https://ponys.ai/ai-video-generator) |
| Explore companion categories | [AI girlfriend](https://ponys.ai/ai-girlfriend) and [AI boyfriend](https://ponys.ai/ai-boyfriend) |
| Browse anime-oriented characters | [Anime AI characters](https://ponys.ai/ai-anime) |

## What is available

- Static product and localization metadata.
- A framework-neutral benchmark Web Component.
- A WordPress shortcode plugin.
- RSS and JSON feeds in six languages.
- An OpenAPI description of public resource endpoints.
- Disclosure language for editorial and creator use.

These resources do not provide access to a private product API and do not
promise affiliate compensation. Publishers retain editorial control over any
review, comparison, or citation.
