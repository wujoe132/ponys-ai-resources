# Kai character SDK record

[Kai on Ponys.ai](https://ponys.ai/characters/kai) is the canonical public page
for the `kai` record in the publisher resource SDK.

## Record fields

| Field | Value |
|---|---|
| Slug | `kai` |
| Locale | `en` |
| Market | `GLOBAL` |
| Canonical URL | [https://ponys.ai/characters/kai](https://ponys.ai/characters/kai) |

## Integration use

Use this stable record in feed readers, publisher widgets, API examples, and
link-health checks. Fetch changing descriptions and media from the public feed
rather than caching them in the identity record. This official data card does
not contain private conversations or user-created content.
