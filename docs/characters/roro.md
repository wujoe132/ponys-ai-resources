# Roro character SDK record

[Roro on Ponys.ai](https://ponys.ai/characters/roro) is the canonical public page
for the `roro` record in the publisher resource SDK.

## Record fields

| Field | Value |
|---|---|
| Slug | `roro` |
| Locale | `en` |
| Market | `GLOBAL` |
| Canonical URL | [https://ponys.ai/characters/roro](https://ponys.ai/characters/roro) |

## Integration use

Use this stable record in feed readers, publisher widgets, API examples, and
link-health checks. Fetch changing descriptions and media from the public feed
rather than caching them in the identity record. This official data card does
not contain private conversations or user-created content.
