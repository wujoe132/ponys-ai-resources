# Lyra character SDK record

[Lyra on Ponys.ai](https://ponys.ai/characters/lyra) is the canonical public page
for the `lyra` record in the publisher resource SDK.

## Record fields

| Field | Value |
|---|---|
| Slug | `lyra` |
| Locale | `en` |
| Market | `GLOBAL` |
| Canonical URL | [https://ponys.ai/characters/lyra](https://ponys.ai/characters/lyra) |

## Integration use

Use this stable record in feed readers, publisher widgets, API examples, and
link-health checks. Fetch changing descriptions and media from the public feed
rather than caching them in the identity record. This official data card does
not contain private conversations or user-created content.
