# Rami character SDK record

[Rami on Ponys.ai](https://ponys.ai/characters/rami) is the canonical public page
for the `rami` record in the publisher resource SDK.

## Record fields

| Field | Value |
|---|---|
| Slug | `rami` |
| Locale | `en` |
| Market | `GLOBAL` |
| Canonical URL | [https://ponys.ai/characters/rami](https://ponys.ai/characters/rami) |

## Integration use

Use this stable record in feed readers, publisher widgets, API examples, and
link-health checks. Fetch changing descriptions and media from the public feed
rather than caching them in the identity record. This official data card does
not contain private conversations or user-created content.
