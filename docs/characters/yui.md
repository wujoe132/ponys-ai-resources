# Yui character SDK record

[Yui on Ponys.ai](https://ponys.ai/characters/yui) is the canonical public page
for the `yui` record in the publisher resource SDK.

## Record fields

| Field | Value |
|---|---|
| Slug | `yui` |
| Locale | `en` |
| Market | `GLOBAL` |
| Canonical URL | [https://ponys.ai/characters/yui](https://ponys.ai/characters/yui) |

## Integration use

Use this stable record in feed readers, publisher widgets, API examples, and
link-health checks. Fetch changing descriptions and media from the public feed
rather than caching them in the identity record. This official data card does
not contain private conversations or user-created content.
