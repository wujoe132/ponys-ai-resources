# Adrian character SDK record

[Adrian on Ponys.ai](https://ponys.ai/characters/adrian) is the canonical public page
for the `adrian` record in the publisher resource SDK.

## Record fields

| Field | Value |
|---|---|
| Slug | `adrian` |
| Locale | `en` |
| Market | `GLOBAL` |
| Canonical URL | [https://ponys.ai/characters/adrian](https://ponys.ai/characters/adrian) |

## Integration use

Use this stable record in feed readers, publisher widgets, API examples, and
link-health checks. Fetch changing descriptions and media from the public feed
rather than caching them in the identity record. This official data card does
not contain private conversations or user-created content.
