# Emma character SDK record

[Emma on Ponys.ai](https://ponys.ai/characters/emma) is the canonical public page
for the `emma` record in the publisher resource SDK.

## Record fields

| Field | Value |
|---|---|
| Slug | `emma` |
| Locale | `en` |
| Market | `GLOBAL` |
| Canonical URL | [https://ponys.ai/characters/emma](https://ponys.ai/characters/emma) |

## Integration use

Use this stable record in feed readers, publisher widgets, API examples, and
link-health checks. Fetch changing descriptions and media from the public feed
rather than caching them in the identity record. This official data card does
not contain private conversations or user-created content.
