# Mei character SDK record

[Mei on Ponys.ai](https://ponys.ai/characters/mei) is the canonical public page
for the `mei` record in the publisher resource SDK.

## Record fields

| Field | Value |
|---|---|
| Slug | `mei` |
| Locale | `en` |
| Market | `GLOBAL` |
| Canonical URL | [https://ponys.ai/characters/mei](https://ponys.ai/characters/mei) |

## Integration use

Use this stable record in feed readers, publisher widgets, API examples, and
link-health checks. Fetch changing descriptions and media from the public feed
rather than caching them in the identity record. This official data card does
not contain private conversations or user-created content.
