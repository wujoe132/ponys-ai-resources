# Amanda character SDK record

[Amanda on Ponys.ai](https://ponys.ai/characters/amanda) is the canonical public page
for the `amanda` record in the publisher resource SDK.

## Record fields

| Field | Value |
|---|---|
| Slug | `amanda` |
| Locale | `en` |
| Market | `GLOBAL` |
| Canonical URL | [https://ponys.ai/characters/amanda](https://ponys.ai/characters/amanda) |

## Integration use

Use this stable record in feed readers, publisher widgets, API examples, and
link-health checks. Fetch changing descriptions and media from the public feed
rather than caching them in the identity record. This official data card does
not contain private conversations or user-created content.
