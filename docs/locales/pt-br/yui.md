# Yui registro SDK da personagem

[Yui on Ponys.ai](https://ponys.ai/characters/yui)：Este registro é a referência oficial de uma página pública de personagem usada pelo SDK para publicadores.

## Campos do registro

| Campo | Valor |
|---|---|
| Slug | `yui` |
| Idioma | `en` |
| Mercado | `GLOBAL` |
| URL canônica | [https://ponys.ai/characters/yui](https://ponys.ai/characters/yui) |

## Uso na integração

Pode ser usado como identificador estável em leitores de feed, widgets públicos, exemplos de API e verificações de links. Descrições e mídias variáveis devem vir do feed público. Não contém conversas privadas nem conteúdo criado por usuários.
