# Ruby registro SDK da personagem

[Ruby on Ponys.ai](https://ponys.ai/characters/ruby)：Este registro é a referência oficial de uma página pública de personagem usada pelo SDK para publicadores.

## Campos do registro

| Campo | Valor |
|---|---|
| Slug | `ruby` |
| Idioma | `en` |
| Mercado | `GLOBAL` |
| URL canônica | [https://ponys.ai/characters/ruby](https://ponys.ai/characters/ruby) |

## Uso na integração

Pode ser usado como identificador estável em leitores de feed, widgets públicos, exemplos de API e verificações de links. Descrições e mídias variáveis devem vir do feed público. Não contém conversas privadas nem conteúdo criado por usuários.
