Embeddable AI Character Quality Card

Add a compact evidence resource to a review, directory, integration page, or creator guide. The Ponys.ai attribution is visible and the host publisher remains in control.

Embed code

<script src="https://wujoe132.github.io/ponys-ai-resources/embed/character-quality-card.js"
  data-locale="en"
  data-target="https://ponys.ai/ai-character-generator"
  async></script>

Supported locales: en, ja, ko, zh-tw, and es. Set data-target to the most relevant public Ponys.ai product path.

No tracking script, cookie, hidden link, or injected review claim is included. Standard campaign parameters are added only to the visible Ponys.ai link.

Editorial use

Publishers may inspect, self-host, modify, or remove the script. The card should not be represented as an independent rating.
