Add a self-contained AI companion benchmark calculator with an optional research attribution.

== Description ==

Ponys AI Companion Benchmark adds a five-dimension calculator for publishers,
reviewers, and researchers evaluating AI companion products.

The calculator measures:

* Memory
* Persona consistency
* Boundaries
* Privacy
* Visual identity

The plugin does not collect analytics, set cookies, create accounts, or contact
external services. Public research and product links are disabled by default.
Publishers may explicitly enable them with the `show_links` shortcode option.

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/` or install the ZIP.
2. Activate the plugin.
3. Add `[ponys_ai_benchmark]` to a post or page.
4. To include the optional research attribution, use `[ponys_ai_benchmark show_links="yes"]`.

== Frequently Asked Questions ==

= Does the plugin track visitors? =

No. It does not set cookies, use local storage, or send analytics.

= Are links added automatically? =

No. Public links are disabled by default. The publisher must explicitly enable
them with `show_links="yes"`.

= Does the plugin require a Ponys.ai account? =

No.
