# Ponys.ai Registry Packages

Source for the official dependency-free resource helpers prepared for npm,
PyPI, RubyGems, Packagist, and crates.io. Each implementation resolves product
links, multilingual feeds, or transparent creator attribution. None injects
hidden links or calls a private API.

- npm: `ponys-ai-resources` (existing published package)
- PyPI: `packages/python`
- RubyGems: `packages/ruby`
- Packagist: `packages/php`
- crates.io: `packages/rust`
- Go modules: `packages/go`
